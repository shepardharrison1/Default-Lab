# Research Plan: Agent Data Exchange

**Date started:** 2026-07-15
**Posture:** Skeptical, evidence-driven. The goal is to determine whether the concept is commercially viable, technically feasible, legally workable, defensible, and worth pursuing — not to validate it.

## Concept under investigation

An independent marketplace, licensing system, and routing layer that (a) detects information gaps inside AI-agent workflows, (b) matches agent applications with proprietary data owners, (c) brokers narrow licensed machine access (API/MCP/feeds), and (d) handles authentication, pricing, metering, attribution, settlement, and publisher payouts. Working name for this document set: **"agent data exchange."**

## Method

1. **Anchor the current market state (July 2026).** Verify via live web search what has happened to the named comparables (TollBit, Cloudflare Pay Per Crawl, Dappier, Microsoft Publisher Content Marketplace, ProRata, ScalePost, Human Native AI, Created by Humans, Bria, Story, AWS Data Exchange, Snowflake/Databricks marketplaces, RapidAPI, Postman, Stripe agentic commerce, x402, Web Monetization, MCP registries, agent-commerce protocols). Do not rely on stale training data; verify existence, funding, partnerships, and product status against primary sources.
2. **Run parallel research workstreams**, each producing one or more numbered deliverables:
   - W1: Competitive landscape (02, competitor-matrix.csv)
   - W2: Demand evidence + agent-application targets (03, 06, agent-targets.csv)
   - W3: Publisher/dataset targets (07, publisher-targets.csv)
   - W4: Vertical ranking + first pilot (04, 14, vertical-ranking.csv)
   - W5: Licensing structures + legal/regulatory risk (08, 11)
   - W6: Business model + unit economics + go-to-market (09, 15, unit-economics.csv)
   - W7: Demand-matching engine + technical architecture (05, 10)
   - W8: Commoditization/moats + sponsored discovery + failure modes (12, 13, 16, failure-modes.csv)
3. **Synthesize** the product definition (01), executive summary (00, under 2,500 words), consolidated source list (sources.md), and the final investment judgment (17) after all evidence is in — so the conclusion is drawn from the research, not before it.

## Source rules

- Prefer primary and authoritative sources: official sites, product/pricing/API/MCP documentation, legal terms, court filings, regulatory guidance, research papers, GitHub, investor materials, credible journalism (Reuters, WSJ, FT, Axios, The Information, TechCrunch for funding confirmations).
- Every significant factual claim carries a direct link and a publication date where available.
- Verified fact vs. inference is labeled. Uncertainty is flagged. No invented funding, revenue, customers, pricing, or partnerships.
- Marketing claims are treated as claims, not proof. Conflicting evidence is highlighted, not smoothed over.

## Key falsifiable questions the research must answer

1. Do agent developers demonstrably pay for licensed proprietary data today, or only complain about its absence?
2. Has any existing pay-per-crawl / content-licensing intermediary shown real transaction volume, or are they all pilot-stage?
3. Can an independent intermediary survive multi-homing and platform internalization (OpenAI/Anthropic/Google/Microsoft/Cloudflare doing this natively)?
4. Is the "demand graph" a real moat or an imaginary one?
5. Is there one vertical where the economics of a pilot close today?

## Output checklist

00–17 numbered markdown files, sources.md, six CSVs (competitor-matrix, vertical-ranking, agent-targets, publisher-targets, unit-economics, failure-modes), all in `research/agent-data-exchange/`. Executive summary < 2,500 words. Final recommendation must be one of: pursue immediately / pursue only through a narrow vertical pilot / pause until stronger demand evidence exists / reject — and it must be decisive.
