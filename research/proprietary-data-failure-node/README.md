# Proprietary-Data Failure-Node Resolution — Research Pack

**Research date:** 2026-07-16  
**Posture:** Skeptical, evidence-driven, falsification-seeking  
**Central question:** Can a platform reliably identify data-caused failure nodes inside AI coding workflows and resolve them through licensed proprietary-data access at prices that work for buyer, data owner, and intermediary—without being internalized by platforms?

## Final recommendation

**Pursue only through a narrow pilot.**

Reject the horizontal “failure-node → licensed data for all coding agents” company as a founding strategy. Most serious coding-agent failures are *not* solvable by purchasing external proprietary data. The commercially testable residue is a **vertical licensing + entitlement gateway** for a small number of high-stakes domain-rule datasets used inside coding/automation workflows—not a new observability platform and not a generic agent data marketplace.

## Relationship to prior pack

A prior pack (`research/agent-data-exchange/`) evaluated a broader agent-data marketplace and recommended a narrow compliance pilot. This pack **does not restate that thesis**. It tests a stricter claim: that **coding-agent observability + automated data-failure detection + proprietary licensing brokerage** is a distinct company.
