# AGENTS.md

## Cursor Cloud specific instructions

This repository is **documentation-only**. It contains no application code, no
package manager, no lockfiles, no build system, no tests, and no runnable
services. The tracked content is:

- `README.md` — project title placeholder.
- `robotics-data-moat-report.md` — a long-form Markdown research report.

Implications for future agents:

- There is nothing to install, build, lint, test, or run. Do not attempt to
  scaffold a package manager, dev server, or CI pipeline unless the task
  explicitly asks you to add application code.
- The environment update/startup script is intentionally a no-op.
- Work in this repo is typically editing/reviewing Markdown documents. Verify
  changes by reading the rendered Markdown rather than by running a service.
